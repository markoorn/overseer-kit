# Creative playbook

The canonical creative process. `ad-brief` references this file rather than restating it,
so there is one place to update. It starts nearly empty and fills with lessons from real
campaigns; every lesson carries the evidence that earned it (which round, what was cut,
who said what), because a rule without an example gets argued with and a rule with one
gets followed.

## Method

### Benefit first; humour earns its place

Every set of concepts includes a straightforward benefit-led route. A joke is kept when it
points at the joy of the feature (what it lets the user feel or get away with), and cut
when it points at the machinery (what the software does internally). State the joy of the
feature in one line before concepting; check each concept against it.

### Artwork and caption have different jobs

The artwork conveys the feature and the benefit on its own, without the caption. The
caption links to the image, argues with it, or presumes guilt; it never explains it. A
caption that would work beside any picture is not finished.

### Present the whole post as a rough, before the rationale

Rough layouts first, caption beneath in a separated area, supporting fields after. People
decide on the thing, not the description of the thing.

## The small brief template

```
Feature / angle:
Audience:
Channel and placement (frame size):
Joy of the feature, in one line:
Concepts (3-4): headline / subhead / caption / hashtags / visual / format / assets /
  grounding / confidence / why it might not work
Nothing generated, nothing spent. Pick one, or another pass.
```

## Production stage gates

Each stage has a gate because every expensive failure below was a gate someone skipped.

1. **Approved concept** (from the brief) and an **approved credit figure** for the round.
2. **Stills round** before any video: start frames, plates, spares. Compare cast faces side
   by side before animating anything.
3. **Video round**, one beat per clip, sound off, cost preflighted per clip.
4. **Review at 0.25 s**, trim to the clean window, log the usable window per clip.
5. **Composite**: real screens only, logo from the file, headline in the real typeface,
   end card from the standard treatment.
6. **Listening review** by a human: speech presence and intelligibility are findings an
   agent leaves pending; it does not infer them from waveforms or mouth movement.
7. **Export with sound on and off** and check both.
8. **Reconcile spend** against the account's transactions ledger, not the balance.
